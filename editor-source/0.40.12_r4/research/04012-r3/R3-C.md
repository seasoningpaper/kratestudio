# R3-C 容量統計與局部介面

沿用原素材庫的 capacity-panel；只追加容量區塊 CSS，進度條為 12px，八類固定低飽和色、圖例、容量與 byte 提示。可換行，不新增大型面板。Logo、導航、六類積木、字型、主題與播放器樣式不變。

依每個實際 IndexedDB 素材 row 的 Blob 大小統計，事件引用次數不增加容量。不同 ID 在底層儲存為不同 row，即使同檔名或共用同個記憶體 Blob 也不得假裝只占一份；未實作跨 ID 內容去重。其他／未知用途與字型列入「專案資料及其他」。總量包含一份邏輯專案中繼資料；不聲稱等於瀏覽器實際磁碟占用（索引、交易暫存與網站其他專案不同）。

所有本容量面板的單位均為十進位 GB；瀏覽器估計可用另列，資料不存在不顯示假數字，並清楚標示「整個網站共用，非保證空間」。

2 項編譯 bundle 的 JSDOM／CSS 測試通過。首次失敗來自 JSDOM 缺 TextEncoder，僅補測試環境標準 Web API，不變更產品來繞過測試。這不是像素比較或真實手機／桌面驗收，後者仍待人工執行。
