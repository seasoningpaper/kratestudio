# KOI Maker 0.40.10 r3

本次保留既有平面 GUI，集中處理音訊生命週期、KOI 程式檔案、積木操作與開場閃爍。

## 音訊

背景音樂、語音、音效分開控制音量與生命週期。音效不再因換到下一張對話而停止，支援循環；語音隨對話切換。停止事件可選擇音樂、語音、音效或全部；音樂停止時會連同動態分軌清除。讀檔恢復循環音效，不重播舊的一次性音效；回首頁與卸載停止遊戲音效。音樂鑑賞暫停背景音樂，離開後恢復。

```text
音樂:bgm.ogg;
音效:birds.ogg -循環 -音量=60;
旁白:蟲鳴鳥叫不會因為這句對話結束而中斷。;
停止音訊:音效;
停止音訊:背景音樂;
停止音訊:全部;
```

`停止音訊:音效 -素材=birds.ogg;` 只停止指定素材。音訊需要先匯入。瀏覽器的使用者互動播放限制仍適用。

## 程式編輯

新增位於事件編輯左側的 KOI 程式編輯，共用專案資料及既有播放器。

| 檔案 | 用途 | 指令 |
| --- | --- | --- |
| script.koi | 綁定劇情；套用時取代該劇情事件，可復原 | 既有 KOI 命令，或 `事件:JSON;` 保留全部事件欄位 |
| screens.koi | 存檔、讀檔、歷史、設定、鑑賞版面 | `畫面:save\|JSON;`；手機使用 `save@mobile` |
| options.koi | 共用遊戲設定 | `設定:JSON;` |
| gui.koi | 電腦／手機 GUI 元件 | `介面:desktop\|JSON;` 或 `mobile` |
| extensions.koi | 建立、更新互動模組 | `模組:JSON;`；劇情用 `互動:名稱;` 引用 |

可新增、改名、刪除檔案，匯入／匯出文字，搜尋取代，使用指令提示與診斷。Ctrl+A/C/X/V 為文字選取與剪貼，Ctrl+Z/Y 為檔案內復原／重做，Ctrl+S 儲存，Ctrl+F/H 搜尋，Ctrl+Space 指令，Ctrl+Enter 套用，F5 試玩，Tab 縮排，Ctrl+/ 切換註解。

程式草稿保存在專案中，編輯不會立即覆蓋事件。按「套用至專案」才更新共通資料。視覺事件修改後可按「從事件更新」重新產生程式；此動作需要確認，不會默默覆寫草稿。這是 KOI 原生編輯器，並非 Python／Ren'Py 相容執行器；不支援直接執行 `.rpy` 或安裝 VS Code 擴充。

GUI 元件 JSON 可引用素材 ID 或完整檔名；找不到的素材會阻止套用。互動模組支援 messages、sns、call、map、investigate、qte、rhythm，與擴充的視覺化編輯共用資料。自訂 Live2D／Spine 等仍需既有的沙盒 HTML 播放器，不會憑程式檔自動取得原生引擎。

## 積木與開場

積木回到單欄連續排列，接回時使用擴大的幾何吸附區。運算積木移動範圍列入小地圖，可刪除、複製／貼上；拖入數值插槽後會移除獨立副本，拖回分類區刪除。分類僅選取時顯示色彩。音訊素材分成音樂、音效、語音，可修改用途。

切換劇情在下一幕素材預載完成後才提交狀態，並預先載入鄰近事件的圖片。首頁不再退回內建教室女孩圖片；開場 Logo／影片以點擊或空白鍵略過，隱藏「略過」文字，保留作者設定的禁止略過及影片可略過時間。
