# P0-C 視覺補驗清單（尚未執行）

開啟同資料夾的 `p0-c-visual-review.html`，使用兩個獨立、固定提交的 React／CSS 畫面比較。檔案完全自含，不需 npm 安裝，不會載入正式網站、主程式、帳戶或專案資料。

此樣本只驗收積木外觀及內容排版，不能取代完整網站的互動、跨模式、儲存或實機觸控測試。兩個 iframe 不是原始網站的完整執行狀態。上方頁面只是驗收工具，不屬於 KOI Maker 的 GUI。

先檢視整體，再放大查看凹凸接點、選單、長文字與多行欄位的邊界。GUI 比較若有差異，區分既有畫面回歸與新增多行／值控制項的必要差異。
