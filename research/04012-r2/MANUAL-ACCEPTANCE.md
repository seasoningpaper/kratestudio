# r2 人工驗收清單（均待使用者執行）

先從正式站匯出含素材的可編輯專案備份，再使用副本；不要清除正式資料。測試結果請附瀏覽器、裝置、畫面寬度、操作順序與前後錄影／截圖。

1. **工具箱**：拖一次角色對話只多一個獨立事件；快速連續拖三次多三個，各有唯一ID。滑鼠放開後延遲點擊、工具箱回放、Escape、畫布外取消不能多新增。repeat會多repeat／內文wait／repeatEnd三筆，但它們屬於同一容器；Undo一次移除整組。
2. **連接**：子串拖移、Alt單塊抽離、C型容器、值積木解除／插入與縮放後吸附；Undo／Redo並重開專案，確認未受影響的積木位置及引用。
3. **區段**：用「謝幕離開」長標題測390／768／1200／1920px；核取方塊、收合、數量、編輯、垃圾桶同列且不互相觸發。刪除先確認內容及跨章風險；取消完全不變，確認只刪本區段；跨repeat邊界須顯示拒絕，Undo完整恢復。
4. **計數與四模式**：本章數不包含section標題；專案總數為各章同一定義加總。新增、刪除、複製、重排後切換事件→積木→程式→流程→事件，計數、ID、參數、變數及跳轉保持；未套用草稿不能無聲覆蓋。
5. **局部GUI**：四分頁等寬／同高度／原順序；深淺色與鍵盤焦點可見。清單無／極細／標準、緊湊／標準／寬鬆可保存。Logo、六分類、字型、主配色、積木凹凸和主要布局與58版比較；未預期變動請回報。
6. **圓角**：模板編輯選對話框，「圓角 px」依序0、4、8與自訂13；桌面／手機、儲存重開、真正遊戲預覽與HTML5匯出均應套用。舊模板預設外觀不變。
7. **播放器**：逐字效果各字速、正常／快進／自動／跨章／存讀檔；過場慢載與連續過場以240FPS錄影。舊景閃回仍未獨立重現，請勿先勾選修復通過。角色同位置重複登退場、BGM／語音／鑑賞切換也需聽感驗收。
8. **儲存**：容量顯示來自真實bytes與現有2GiB上限（約2.1GB）；不是已驗證5GB。用副本測儲存／重開／備份還原，不要對正式專案做大容量破壞性測試。
9. **Windows本機**：依WINDOWS-SETUP.md，以Node24、npm.cmd ci、npm.cmd run build、npm.cmd test、npm.cmd start執行，開啟固定127.0.0.1:4173。正式站和本機資料不自動共用，先匯出／再匯入副本。Windows11實機尚未執行。
