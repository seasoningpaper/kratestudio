## 氣象資料與來源查證

使用中央氣象署管理的官方 AWS Open Data bucket `cwaopendata`，無授權碼，公開 GET，非第三方轉載：

- https://registry.opendata.aws/cwa_opendata/ 已讀取，確認管理機關、bucket、region、公開取用及授權連結。
- https://opendata.cwa.gov.tw/dataset/observation/O-A0001-001 已讀取欄位說明。
- https://opendata.cwa.gov.tw/devManual/description 已讀取，REST API 需要會員授權碼，本案沒有取用或捏造他人金鑰。
- https://www.cwa.gov.tw/V8/C/S/eservice/rss.html 已讀取，RSS 使用限制不適合衍生氣象介面，因此未解析 RSS 製作預報。

實際讀取的公開 JSON：

1. Observation/O-A0001-001.json
2. Observation/O-A0003-001.json
3. Forecast/F-D0047-089.json
4. Forecast/F-D0047-091.json

預設新北市。選擇最近的有效 WGS84 測站，標示測站名、觀測時間與來源。縣市逐時及一週預報分開顯示，體感與露點明確標記為預報。-99 等缺值不當成溫度或雨量，未提供的紫外線或能見度不偽造。每日溫度範圍整合同日開始的預報時段，降雨顯示該組時段最高機率。官方未提供後段降雨機率時保持缺值。

`/api/weather` 僅接受 GET/HEAD，固定官方來源清單、12 秒上游 timeout、部分失敗處理、短期快取與併發合併，沒有任意 URL 代理。開發環境 Node 對外請求逾時，但相同官方 S3 已確認 CORS `*`；加入瀏覽器直接讀取同一官方來源的備援。這不是更換氣象供應商，無靜態數字假裝即時。

精確定位只在點選後呼叫 geolocation，`enableHighAccuracy:true`，不儲存、不送至本站或氣象 API。瀏覽器選最近測站，顯示距離及裝置回報精度。拒絕、失敗或範圍不在台灣附近時仍可手動選縣市。不使用上傳畫面裡的住家地址。

## 工具功能

- 線上時鐘：秒級時鐘、時區、12/24 小時、全螢幕申請或不支援回饋，裝置時鐘來源。
- 計分板：兩隊名稱、加減幅度、負分選項、歸零、最近 100 次復原。
- 文字比對：逐行 LCS、新增/刪除/相同標記，CRLF 正規化，30,000 字元 / 400 行限制，純文字輸出。
- 時區轉換：IANA 時區與所選日期，處理日光節約不存在及重複時段，跨日輸出。
- 輪盤：2–24 個項目、crypto 拒絕採樣公平抽選、五圈減速旋轉、結果與指針落點對應，reduced-motion 立即顯示。
- 翻譯：MyMemory 短句翻譯、複製、500 UTF-8 位元組檢查、額度/連線失敗回饋。按鈕前明確揭露會傳送原文給外部服務。未呼叫投稿或記憶庫寫入 API。官方規格 https://mymemory.translated.net/doc/spec.php 已讀取。
- 酷文字：數學粗體、無襯線、等寬、全形、圈圈字，保留中文與 emoji，複製及錯誤回饋。UI 自身維持系統字體。
