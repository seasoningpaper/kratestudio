# P1-A 人工驗收（未執行，開發版尚未發布）

正式站仍為 0.40.10_r49，以下新功能需在 P1-A 開發版提供預覽／另行核准發布後操作；不要在正式站找尚未部署的控制項。

1. 先匯出自己的專案備份，再開測試副本。在「專案工具 → 遊戲畫面」選「背景」元件，從「背景圖片」挑已匯入素材，確認預覽立即替換。
2. 在沒有背景事件的章節重做一次，應只增加一個章節開頭背景事件，原對話 ID、分支與跨章節跳轉仍指向原事件。Undo／Redo 後比對數量及程式來源。
3. 以既有「匯入目前元件圖片」加入新 PNG／JPEG，確認出現在素材庫且套用到當前背景；不要只新增空白按鈕。
4. 切換填滿／完整顯示／延展填滿、水平 25%、垂直 75%。具尺寸資訊素材測試 125% 縮放，確認對話框、立繪及 UI 沒被一起縮放。缺尺寸素材不應出現縮放控制。
5. 到首頁編輯器設定不同的背景，確認不會改動劇情背景。若原本有首頁影片，先用既有影片設定停用，再驗收圖片。
6. 分別到存檔、讀檔、設定畫面，選不同背景並改位置；切換電腦／手機版面，確認各自設定保留。試玩相同頁面，背景在按鈕與存檔內容下層。
7. 儲存後重新載入，匯出並匯入測試副本，確認素材 ID、圖片、模式、位置與縮放都一致；試玩切換兩張背景後，第一張的裁切／位置不殘留。
8. 用電腦與手機截圖比較原有介面。除了本包必要背景控制項及自己選定的圖片，配色、字型、按鈕位置、積木外型、頁面布局應保持。

結果逐項記錄通過／失敗，不以本機 JSDOM 或 DOM 一致性代替實際畫面。
